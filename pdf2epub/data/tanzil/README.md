# Tanzil Quran text

Verbatim copies of the Tanzil Quran text, version 1.1, downloaded on 18 October 2026 from
https://tanzil.net/download/ in "Text (with aya numbers)" format (`sura|aya|text`).

| File | Tanzil options |
| --- | --- |
| quran-uthmani.txt | Uthmani, pause marks, sajdah signs |
| quran-uthmani-plain.txt | Uthmani, no pause marks |
| quran-uthmani-min.txt | Uthmani Minimal, pause marks, sajdah signs |
| quran-simple.txt | Simple, pause marks, sajdah signs, superscript alefs |
| quran-simple-plain.txt | Simple, no pause marks, no sajdah signs, no superscript alefs |
| quran-simple-clean.txt | Simple Clean (no diacritics or symbols) |
| quran-data.xml | Sura metadata (Arabic names, aya counts) |

Note: in these files the basmala is prepended to verse 1 of every sura except suras 1 and 9.
